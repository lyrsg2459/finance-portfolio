# Notes 

## Key Python Concepts

| Concept | What It Does |
|---|---|
| Variable | A "box" with a given name that stores information, e.g price = 30. |
| Function | Stores formula and a sequence of code, and executes them with given inputs. |
| List | Values collected in an order; Can be changed after creation e.g [1, 2, 3]. |
| Tuple | Values collected in an order; Can't be changed after creation e.g (1, 2, 3). |
| Dictionary | Groups keys to arbitrary value. Accesses value using dictionary["key"]. |
| Loop | Repeats a block of code for a specified number of times. |
